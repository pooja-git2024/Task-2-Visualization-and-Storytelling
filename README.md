Task 2 – Data Visualization & Storytelling

This project focuses on analyzing the Superstore dataset and creating a set of visual dashboards in Power BI to communicate key business insights effectively.

📊 Dashboard Overview

The Power BI report contains the following pages:

1️⃣ Overall Sales Dashboard

Shows total sales, total profit, and total quantity sold

Displays yearly and quarterly sales trends

Highlights top-performing states

2️⃣ Region & State Analysis

Comparison of sales and profit across four regions

State-wise performance with map visualization

3️⃣ Category & Sub-Category Analysis

Analysis of Categories: Technology, Furniture, Office Supplies

Identifies high-profit and low-profit sub-categories

4️⃣ Executive Summary (Key Insights)

Total Sales: $2.30M

Total Profit: $286.4K

Total Quantity Sold: 38K

Technology is the highest-profit category

California is the top revenue-generating state

West region contributes the highest profit
